# file_name_lister

This simple py code will scan and list all files/folders/subfolders in a text document. 
Place "file_name_lister" in the folder you want to scan, run it, this will create a text document named "file_analysis.txt" in the same folder. 
This will create a list/tree of all the files/subfolders in that directory. Also will list all types of files (extentions) 

EXAMPLE :

hfs-windows-x64-0.56.0.zip

Internet.Download.Manager.v6.42.27.zip

File Type Summary:
=================
Total files: 12193

Extension | Count
--------- | -----
.xml      |  9938
.cs       |   860
.ino      |   272

Creating another text file in the same directory will create a new .txt file named "file_analysis_1...._2..._3..."... and so on...

This is comepletely open source, use any text editor to check the base code and feel free to use anyway you like.
